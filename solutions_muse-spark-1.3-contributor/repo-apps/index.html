About Repo Apps

Loading a repoPaste any github.com/owner/repo (also /tree/branch/path or /blob/branch/file) and press Open. Default branch is auto-detected; no token needed for public repos. Source vs PreviewSource only displays text — nothing executes. Preview as App fetches the HTML + its local CSS/JS/images, inlines them in order, and executes inside a sandboxed iframe. Use Preview only for standalone pages (no backend). MarkdownRendered by default (sanitized). Toggle to Raw to see source. Relative images/links resolve against the file's repo path; broken ones show a placeholder. Dependency resolverLocal src/href → resolved relative to the HTML file → fetched via raw.githubusercontent.com (cached, deduped, order-preserved). Stylesheets are inlined (avoids raw MIME nosniff blocking); CSS @import/url() rewritten recursively with circular-import guard; external CDN URLs left untouched. GitHub API limitsUnauthenticated: ~60 req/hour/IP. Directory + file fetches are cached; filename search uses one recursive-tree request. On 403/429 the app shows reset time. Private repos are unsupported (no auth). SecurityRepo content is untrusted: Markdown is sanitized, eval/new Function never run on repo code in the parent, previews use <iframe sandbox="allow-scripts allow-modals allow-forms allow-popups …"> without allow-same-origin so previews get an opaque origin (no access to this app's JS/localStorage). Sandbox ≠ perfect safety. Browser limitsfile://-safe (no modules/workers). Some sites block framing/hotlinking via CSP/CORS; huge files (>~1.5MB) are truncated with download fallback; binary files show metadata + download.
