About RepoLens · browsers · file:// notes · implementation

Launch: open index.html in a modern browser. No Node, no server, no build.

Supported browsers: current Chrome, Edge, Firefox, Safari — including mobile Safari and Chrome for Android. Requires fetch, async/await, localStorage.

file:// notes: the app runs from file://. CDN libraries (marked, DOMPurify, highlight.js) need internet on first load. localStorage may be blocked in some private modes or strict file:// contexts (notably older mobile Safari); the app falls back to in-memory history/theme for that session and shows a toast explaining persistence is unavailable. If CDN is offline, Markdown falls back to raw source and code shows without highlighting. For the most reliable history persistence, serve over http(s) or allow site data.

Implementation: GitHub REST /repos/{o}/{r} for metadata (discovers default_branch), /contents/{path}?ref=branch for listings, download_url (+ contents-API fallback) for files, /git/trees/{branch}?recursive=1 for quick-open. Marked + DOMPurify for GFM rendering with relative-link/image resolution to raw.githubusercontent.com; internal .md links route inside the app. highlight.js with extension→language map, line numbers, wrap + font-size controls. History/bookmarks/theme in localStorage with memory fallback; in-memory dir + metadata cache; request-id guard against stale async races; 15 s timeouts; rate-limit messaging from X-RateLimit-*.
