Switchcraft ⚙️ CSS-Only Toggle Gallery

Six hand-crafted toggle switches. Every on/off animation is pure CSS (transition / @keyframes driven by :checked). JavaScript only handles the page theme and the copy buttons.

Click a switch, click its label text, or focus it with Tab and press Space. All six work with JavaScript disabled.

1. Classic Slide

Rounded pill track with a knob that slides across. Green when on.

2. Neon Glow

Dark track; when on, knob and track glow with a cyan box-shadow.

3. Squishy

Knob stretches mid-slide, then settles. Elastic return on switch-off.

4. Day / Night

Sun ☀️ slides into moon 🌙; sky-blue track fades to night.

5. Pulse

When on, the knob emits a repeating ripple ring via @keyframes.

6. Flip Lock

Knob slides and rotates 180°, flipping 🔓 to 🔐.
