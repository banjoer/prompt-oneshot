About RepoLens

RepoLens turns any public GitHub repository into a compact, mobile-first reading experience. Browse nested folders, inspect highlighted source with line numbers, and read Markdown in a clean rendered view — with one-tap history so you can come back later.

Supported browsers

  • Current Chrome, Edge, Firefox, and Safari — including Chrome for Android and mobile Safari (iOS 16+ recommended).
  • Launch by opening this single index.html file. No server, build step, or installation is required.

Opening from file://

  • GitHub API and CDN requests work from a local file in current browsers. If a CDN is unreachable, RepoLens falls back to built-in Markdown and highlighting support.
  • Some browsers restrict localStorage for local files or in private windows. In that case the library, bookmarks, and theme still work for the session, and a notice appears on the home screen.
  • Private repositories are not accessible without authentication. RepoLens intentionally uses GitHub's unauthenticated public API.

Implementation overview

  • GitHub API: REST v3 metadata, Contents API for directory listings and file bytes, Branches API for slash-containing ref resolution and the branch picker, and the recursive Git Trees API for quick-open search. Metadata and directory responses are cached in memory with TTLs; stale responses are discarded using request sequence tokens and AbortController.
  • Markdown: marked (GFM) with DOMPurify sanitization. Links and images resolve against the current file's repository path; internal links are routed inside RepoLens, external links open in a new tab with rel="noopener noreferrer". A small built-in renderer is used if the CDN is unavailable.
  • Syntax highlighting: highlight.js with a custom dual-theme palette, per-line markup, a sticky line-number gutter, wrap and font-size controls.
  • Persistence: localStorage for repository history, per-repository bookmarks, theme, and reader preferences, with an in-memory fallback when storage is blocked.
  • Navigation: hash-based routing (#/repo/owner/name?b=branch&p=path&v=tree|blob) so browser back/forward and deep links work without a server.
