# Mosaic Studio — Layered Pixel-Image Editor

**Difficulty:** Hard  |  **Stack:** HTML/CSS/JS (vanilla, single file, canvas)  |  **Estimated time:** 3–8 hours

## The Problem

Icon designers, game jammers, and sprite artists need a small, dependable pixel editor that opens instantly, draws exactly the pixel under the cursor, layers cleanly, undoes gracefully, and saves locally — without accounts, cloud uploads, or a week of onboarding. What usually breaks is precision: blurry canvas scaling, strokes that gap when the pointer moves fast, layers that flatten into mush, or exports that come out the wrong size. Build the compact professional alternative: a single-file, local-first pixel editor with a real document model, a genuine layer compositor, crisp rendering at every zoom, and PNG plus project export that round-trips.

## Requirements

1. Deliver a single self-contained `mosaic.html` file using only vanilla HTML/CSS/JS — all markup, styles, and logic inside it. It must work when opened directly from disk (`file://`); no server, no build step, no libraries.
2. **New-document dialog:** on launch (and via a `New` button) offer a dialog with document name, width/height inputs, and background choice (`transparent` or `opaque` with a color). Provide presets `16×16`, `32×32`, `64×64`, `128×128` plus custom sizes from 8 to 128 per side with inline validation. Confirm before replacing a document with unsaved changes.
3. **Starter document:** the first run (no saved state) procedurally generates a finished 64×64 document titled **Sunset Courier** in code — an original composition of a small courier vehicle crossing a warm sunset landscape — built from at least 3 named layers (e.g. `Sky`, `Landscape`, `Courier`) drawn with rectangles, gradients-by-hand, dithered bands, or pixel runs. It must demonstrate the starter palette, transparency (at least one see-through region), and crisp rendering; it must be generated by code, not embedded as an image.
4. **Sharp rendering:** pixels render without interpolation at every zoom (`image-rendering: pixelated` on the display canvas, offscreen document canvases at exact logical resolution). Pointer-to-pixel mapping is DPR-aware and exact at all supported zooms; a coordinate readout shows the pixel under the cursor (e.g. `(12, 40)`), and painting outside the document is clipped, never drawn.
5. **Zoom/pan/grid:** zoom from 100% to 3200% via toolbar buttons, `Ctrl/Cmd +`/`-`, and a `Fit` command, with a visible zoom readout (e.g. `800%`). Pan with a Hand tool, `Space`-drag, or middle-mouse drag. A toggleable pixel grid appears at useful zooms (e.g. ≥ 400%) and never at 100%.
6. **Tools:** Pencil (`P`), Eraser (`E`, paints transparency), Line (`L`, Shift constrains to orthogonal/45°), Rectangle (`R`, outline + filled modes), Ellipse (`O`, outline + filled modes), Fill (`F`, contiguous flood fill on the active layer bounded to the exact source color, 4-connected by default), and Eyedropper (`I`, or Alt-click with any tool samples the visible composite). Brush sizes 1/2/4/8 produce hard-edged squares. Strokes use pointer capture plus segment interpolation so fast drags leave no gaps. Every tool has a visible selected state, an accessible name, and a tooltip or hint.
7. **Layers:** a layers panel supports add, rename (double-click or button), delete (with confirmation when non-empty; never delete the final layer), reorder (up/down buttons or drag), show/hide toggle, per-layer opacity slider (0–100% with live composite preview), and click-to-select the active layer. At most 8 layers; the app refuses a 9th with a plain message. Painting always affects only the active visible layer — attempting to paint on a hidden layer is blocked with a hint. Layer order, visibility, opacity, and names persist and export correctly.
8. **History:** at least 50 undo steps; a single pointer stroke (down → move → up), a fill, or one layer operation counts as exactly one step. Provide Undo/Redo buttons plus `Ctrl/Cmd+Z` and `Ctrl/Cmd+Shift+Z` (or `Ctrl/Cmd+Y`). New edits after undo correctly invalidate the redo branch.
9. **Palette:** a 16-swatch curated starter palette matching Sunset Courier (warm sunset hues + courier accents + transparency indicator), a custom color control (native `<input type="color">` plus hex text field, kept in sync), and a recent-colors row holding the last 8 distinct colors. Transparency is shown as a checkerboard swatch, never as white.
10. **Persistence:** autosave the full project (document, layers + pixels, palette, tool settings, active layer, viewport) to `localStorage` under a versioned key (e.g. `mosaic.v1`) after each committed change, with a restrained dirty/saved indicator (`● Unsaved` / `✓ Saved`). Reloading restores the session. Corrupt or version-mismatched saved data triggers a safe recovery path (offer `Reset to starter` / start blank) instead of a hang or blank crash. A `Reset` control with confirmation restores the Sunset Courier starter.
11. **Export/import:** export the visible composite as PNG at selectable scales (at least 1× and 4×, nearest-neighbor) with transparency preserved, downloading under a safe filename derived from the document name; export the full editable project as versioned JSON and re-import it with schema validation and a useful error message on bad files. State near the import control that images never leave the machine.
12. **Chrome and help:** the workspace shows an app bar (identity, document name + dimensions + zoom + dirty state, undo/redo, export), a tool rail, a central canvas stage, a right inspector (color/palette + layers), and a status bar (dimensions, cursor coordinates, zoom, contextual hint). A keyboard-shortcuts dialog lists all tool and action shortcuts. All controls are real — no dead buttons or placeholders.
13. **Accessibility basics:** semantic buttons/dialogs/labels, visible focus rings, dialog focus containment with `Escape` to close and focus restoration, keyboard access to every non-canvas control, non-color-only indicators for active tool/selected layer, and `prefers-reduced-motion` respected. The canvas element carries a text description (document name, dimensions, active layer, note that editing is spatial).
14. **Sign-off:** the page must display, somewhere easy to spot (e.g. a footer), the date and time the solution was produced and the model/author that produced it (e.g. `Built 2026-10-29 14:32 by <model-name>`), plus a matching header comment at the top of the file.

## Constraints

- One file only: `mosaic.html`. No external CSS/JS files, no CDNs, no frameworks, no web fonts, no images, no build step.
- Standard browser APIs only: Canvas 2D, DOM, `localStorage`, `JSON`, `Blob`/download links. No network calls of any kind.
- Document sizes 8–128 per side; layers ≤ 8; undo ≥ 50 steps. Logical pixels are integers — no sub-pixel painting.
- Must run by double-clicking the file (`file://`) in a current Chrome/Firefox/Edge/Safari. Usable at 1440×900; no horizontal page overflow at 390px wide (panels may collapse into tabs/drawers but canvas interaction and core tools stay reachable).
- Pixel data must live in a real document model (per-layer pixel stores), never only as the visible canvas bitmap.

## Deliverable

- One file: `mosaic.html`
- Run: open `mosaic.html` in any modern browser (double-click it, or `File → Open`). No install, no server.

## Done When

- [ ] The page opens from `file://` showing the generated Sunset Courier 64×64 artwork with at least 3 named layers and no console errors.
- [ ] Pixels are razor-sharp at 100% and 800%+; the coordinate readout tracks the cursor exactly and painting never leaks outside the document.
- [ ] Zoom reaches 100%–3200% with a correct readout, `Fit` frames the document, grid toggles at high zoom, and Hand/Space/middle-drag pans.
- [ ] Pencil/Eraser with sizes 1/2/4/8 draw hard-edged squares; fast drags leave no gaps; Line/Rectangle/Ellipse (outline + filled) commit correct shapes; Fill floods only the contiguous matching region; Eyedropper/Alt-click picks the composite color.
- [ ] Layers add/rename/reorder/hide/opacity-adjust correctly; painting targets only the active visible layer; deleting the last layer is refused; an 8-layer cap is enforced with a message.
- [ ] A three-stroke sequence undoes in three steps and redoes cleanly; a new stroke after undo clears the redo branch.
- [ ] Custom colors, hex input, and the 8-slot recent row work; the transparency swatch is distinguishable from white.
- [ ] Reloading the page restores document, layers, palette, and tool state; corrupting the `localStorage` value by hand and reloading offers recovery instead of a broken page; `Reset` with confirmation restores Sunset Courier.
- [ ] PNG export downloads 1× (64×64) and 4× (256×256) images that open correctly with transparency intact; project JSON export re-imports to an identical document, and importing a malformed file shows a readable error.
- [ ] The dirty/saved indicator flips correctly, the shortcuts dialog opens, and every visible button does something real.
- [ ] The sign-off (date/time produced + model/author) is visible on the page and in a source header comment.
